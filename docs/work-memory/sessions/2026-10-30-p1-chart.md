# 第一批 P1 图表

## 背景与范围

同步记录，未取得任务标识。全功能审查（`2026-10-30-full-feature-audit`，在 `claude/p1-order-safety` 分支上）第一批的第五组：C1，并入 C14。分支 `claude/p1-chart`，基于 `dev` `d99c2bc9`，与其他组互不依赖。

## 结论与依据

- **官方依据（2026-10-30 抓取的前端包）。** 官方数据源同样 `has_weekly_and_monthly: false`、支持 `1W`、`1M`，`getBars` 直接按库请求的分辨率取数，不与图表目标分辨率比较。官方持仓强平线文案为 `Liq. Price `。
- **C1 根因。** `datafeed.ts` 的 `matchesHistoryTarget` 用 `String(resolution) === String(target.resolution)`。周线、月线图表的目标是 `1W`、`1M`，库请求的是 `1D`，历史与实时订阅都被当作过期请求取消。取消返回空结果后，库缓存了空的日线，切回 `1D` 也是空。
- **C1 修复。** `lib/chart/resolution.ts` 新增 `getDatafeedRequestResolution`（`D`、`1D`、`W`、`1W`、`M`、`1M` 映射为 `1D`，其余原样），守卫按它比较。流键仍由请求的分辨率得出（`COIN:1d`），与历史请求身份一致；目标代次照旧负责切换时的失效。
- **C14。** `TradingViewOverlayLabels` 增加 `liquidation`，由 `use-tradingview-overlay-lines.ts` 传入 ``t`Liq. Price` ``（已有译文）；持仓线数量改为 `numberFormat.formatDecimalString(getToolbarAbsoluteSize(szi))`，不再用 `Big#toString`（会随数字格式设置换分隔符，也不会出现指数记法）。
