## 颜色不能只按参考色值验收

当前项目测试要求小字号文字对比度至少为 4.5:1。应从主题底色开始，按实际绘制顺序合成悬停层和深度层，再计算文字对比度；只测试纯白或纯深色底会遗漏问题。

以下为计算样式所对应的颜色合成值，不是对整张截图的像素采样。深度覆盖位置取透明度 0.15；它不代表所有报价的背景均相同。

| 场景 | 买盘价格 | 卖盘价格 |
| --- | --- | --- |
| Sairn 浅色，深度覆盖 | 4.33:1 | 4.12:1 |
| Sairn 深色，深度覆盖 | 4.63:1 | 4.99:1 |
| Sairn 深色，白色 0.06 悬停层再叠深度 | 3.95:1 | 4.24:1 |
| Hyperliquid 桌面，采样悬停层再叠深度 | 4.15:1 | 4.46:1 |

参考终端自身的采样悬停组合也没有全部达到项目目标，因此不把参考页面当作可访问性合格证明。Sairn 手机紧凑表头 `#98A2B0` 在白底上约为 2.58:1，也需要修复。

## 推荐实施顺序

### 1. 先明确文字与图形的颜色职责

现行 `AGENTS.md` 要求价格、深度和图标共用相同颜色，同时固定深度透明度；实现遵守了这些值，但叠加后的文字可读性仍有不足。实施前先修订这处契约冲突。

- 保留深度条和模式图标的现有色值；深度条继续使用 0.15 透明度及现有方向。不修改全局市场涨跌色。
- 增加订单簿价格文字的语义 token，使文字和深度图形可以分别验收；深色默认可继续引用现有买卖色，浅色采用满足叠加背景对比度的同色系前景。
- 为订单簿定义经过验证的悬停反馈。优先用边界强调配合克制背景，不直接复制参考悬停色，也不继续无条件使用通用白色悬停层。具体 token 值由深浅主题的合成对比度测试确定。
- 手机紧凑表头使用现有 `text-fg-muted` 等可读文字角色，与桌面表头语义一致，保留字号和布局。
- 将数量变化的起始色及过渡过程纳入颜色验收；保留 1.8s 单次变化、市场/分组切换重置与 reduced-motion 行为。如需调整闪动色，同步修改其精确色值契约。

涉及文件：`apps/terminal/src/styles.css`、`apps/terminal/src/components/trade/orderbook/orderbook-row.tsx`、`apps/terminal/src/components/trade/mobile/mobile-book-view.tsx`，以及共享价格类的其他消费者。

### 2. 分离普通交易与布局调整

当前 `use-desktop-grid-layout.ts` 固定启用缩放；`s/sw/se` 手柄的高层级命中区覆盖最后一行。项目只有“桌面布局 → 重置”入口，没有可复用的编辑状态。

推荐在现有设置区域增加临时的“调整布局”状态，初始关闭，退出调整后关闭，页面重载后也关闭；已有网格几何仍按原规则保存、恢复。关闭时真正禁用缩放命中区，不能只设置透明度。开启/关闭通过现有 `resizeConfig.enabled` 完成，不重建终端面板。

开启调整时保留 Sairn 所需的横向和纵向联动方向，不照搬参考仅右下角手柄的配置。使用清楚可见、可操作的边界手柄，令报价内容和缩放命中区分离；外层负责手柄，内层负责内容裁切。验收同时证明手柄可拖动和报价可选，不能仅降低层级导致手柄不可用。不得增加一行底部空白或裁切价格来避让。

涉及文件：`apps/terminal/src/components/trade/layout/use-desktop-grid-layout.ts`、`apps/terminal/src/components/trade/components/global-settings-modal.tsx`、布局状态、网格容器与手柄样式。临时编辑状态不写入已保存几何，也不影响账户、订单类型或语言状态。

### 3. 修复报价行的语言订阅

`OrderbookRow` 的 core `t` 调用不会订阅语言，而 memo 行在行情不变时可能不重渲染。按[国际化规范](i18n-presentation.md)改用响应式翻译依赖；保留 memo、价格键、焦点、输入内容与选价业务逻辑，不通过 locale key 或整页刷新更新文字。

### 4. 补齐组合验证后再完成修复

| 验证 | 通过条件 |
| --- | --- |
| 合成颜色 | 深浅主题，无深度、部分深度、完整深度，以及悬停、焦点和数量变化状态；价格、表头、数量文字达到项目对比度目标 |
| 真实网格与报价组合 | 使用真实 OrderbookPanel、RGL 与生产 CSS；默认及退出编辑后，末行左、中、右和角落的指针命中属于报价 |
| 编辑模式 | 开启后手柄可达，手柄外的可见报价仍可选；横纵缩放遵守 min/max、共享边界和保存恢复；退出后报价交互正常 |
| 几何稳定 | 1661×1265、1238×1305、390×844，并检查断点和半像素高度；双边、仅买盘、仅卖盘均完整显示真实行，工具栏与账户边界不随行情深度变化 |
| 语言切换 | 固定且不更新的行情行，英→中→英；可访问名称和打开的提示跟随变化，DOM 身份、焦点、选价值不变 |
| 安全与数据回归 | 保留现有过期/缺失/错误快照禁用、精确累计计算、动画与缓存身份检查 |

现有测试存在两处重要盲区：`desktop-grid-layout.fixture.tsx` 使用文本代替真实订单簿，也未挂生产 `desktop-terminal-grid` 类；`orderbook-layout.fixture.tsx` 不包含 RGL。分别通过无法证明二者组合后不遮挡。现有无行情的国际化 mock 也不能证明 memo 报价行的语言更新。

实施完成后运行相关主题、报价行、size-cell、布局和语言回归，以及改动文件的 Biome、terminal TypeScript 检查；新增浏览器组合 fixture 使用独立且不嵌套的 Vite 依赖缓存，遵循[运行时防护规范](runtime-guardrails.md)。
