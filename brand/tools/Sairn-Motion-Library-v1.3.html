04 / INTEGRATION

直接用 SVG，或内联渲染。

// <script src="sairn-motion.js"> 后，或 require('./sairn-motion.js')
const { motionCSS, renderMotion, renderGlyph } = window.SairnMotion;

// 页面内联：样式注入一次，状态切换只改属性
document.head.insertAdjacentHTML('beforeend',
  `<style>${motionCSS()}</style>`);

host.innerHTML = renderMotion('awaiting-result', {
  theme: 'on-dark', label: '等待成交结果', embedStyle: false,
});

// React
const html = useMemo(() => renderGlyph('pending',
  { theme: 'on-light', size: 20 }), []);
return <span dangerouslySetInnerHTML={{ __html: html }} />;

文件：svg/<外观>/<动效>.svg 为动态版，svg/<外观>/static/ 为静态终态，glyphs/<外观>/ 为状态符号；SVG 不含脚本、字体与外部资源。内联渲染用 ZIP 中的 sairn-motion.js（附 .d.ts）。

减少动态效果：外部 <img> 引用时用 <picture> 为 (prefers-reduced-motion: reduce) 指定静态文件；内联时在任一祖先设 data-motion-reduced="true"。

尺寸：交易进行中插图 ≥64 px，结果插图 ≥48 px；更小处用状态符号。按钮加载用 16 px 专用轮廓。

对比度：加载与状态动效的最暗帧不低于 3:1（深色底透明度 ≥0.55，浅色底 ≥0.78）。骨架占位不在此列。

交易状态的使用边界
  • 提交中不等于成交；动画结束不会切换状态。
  • 超时显示「结果未知」，先核对订单，不自动重试下单。
  • 「已确认」只在服务端返回确认后显示；文案区分受理、挂单、部分成交、完全成交。
  • 关闭取消弹窗不等于撤单成功。
纯 HTML 用法与真实进度
  • <picture><source media="(prefers-reduced-motion: reduce)" srcset="svg/on-dark/static/page-loading.svg"><img src="svg/on-dark/page-loading.svg" width="80" height="80" alt="加载中"></picture>
  • 外部 SVG 不继承宿主颜色；mono 需内联才能继承 currentColor。
  • renderMotion('progress', { progress: 42 }) 只接受 0–100；之后用 setProgress(svg, value) 更新。
