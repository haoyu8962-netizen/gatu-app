# Deploy fixtures

The device-validation evidence fixture and the legacy one-time-ticket client and server fixtures were removed with the ticket endpoint and the real-device evidence validator when phone pairing became a client-only transfer ([ADR 0015](../../docs/adr/0015-link-device-alignment.md) D7 and D8, [simplification plan](../../docs/link-mobile-device-simplification-plan.md)). This directory is kept for future deploy fixtures.
